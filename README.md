# ACS Prolonged LOS Risk Calculator

This repository hosts a research-use web calculator for estimating the probability of prolonged hospital stay (>8 days) in patients with acute coronary syndrome using information available within the first 48 hours after hospital admission.

- Research use only.
- Single-center model with internal holdout validation.
- External validation is required before broader clinical implementation.

Model version: September 2026 (48-h model)
